Git dev → main → Release

Làm việc trên dev, xác nhận pull request, CI/ZIP và GitHub Release sau khi merge main.

Quy tắc nhánh

dev nhận mọi thay đổi đang phát triển. main chỉ cập nhật khi chủ repository chốt và merge Pull Request. CI chạy kiểm tra trên cả dev/main, release ZIP + GitHub Release chỉ chạy sau push vào main.

git clone https://github.com/PhuNope/Cocos-Splines.git
cd Cocos-Splines
git switch dev
# chỉnh sửa, test, commit
git add .
git commit -m "fix: offset arc speed and morph preview"
git push origin dev

Đường dẫn

  • Source đang phát triển — dev
  • Bản ổn định — main
  • GitHub Actions
  • Releases
Workflow yêu cầu tăng version trong package.json mỗi lần release để không trùng tag. Không tự động merge main.
