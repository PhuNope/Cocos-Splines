Length Monitor / Modifiers

Event độ dài đường cong và hệ keyframe điều chỉnh speed, offset, width, scale, roll.

SplineLengthMonitor

Theo dõi chiều dài hiện tại của Spline, phát event khi tăng, giảm hoặc vượt ngưỡng. Gọi checkNow() để kiểm tra ngay; reset() để đổi baseline.

const length = monitor.currentLength;
monitor.AddOnChangedEvent(this.onChanged, this);
monitor.AddOnCrossAboveEvent(this.onAbove, this);
monitor.AddOnCrossBelowEvent(this.onBelow, this);
monitor.checkNow();

SplineModifiers

Định nghĩa keyframe tại progress 0..1, nội suy Linear/SmoothStep. Các giá trị hỗ trợ: Offset, Scale, Width, Speed, Roll.

const v = modifiers.sample(0.5);
console.log(v.offset, v.scale, v.width, v.speed, v.roll);
const at3Units = modifiers.sampleDistance(3);
