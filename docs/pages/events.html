Trigger & Events

Bản đồ callback, đăng ký/hủy listener và sự khác biệt giữa EventHandler với callback runtime.

Trigger

Đặt SplineTrigger ở tiến độ bằng Normalized Distance/Distance/Spline t. Chọn Trigger Direction, Work Once hoặc Once Per Follower. Khi Animate vượt marker, sự kiện được gửi trong gameplay.

trigger.AddOnCrossEvent(this.onCross, this);
trigger.RemoveOnCrossEvent(this.onCross, this);
trigger.resetTrigger();

Runtime callback

Tất cả API có dạng AddOn...Event(cb, target) và RemoveOn...Event(cb, target). Callback giữ nguyên this của target, đăng ký trùng bị bỏ qua. Dữ liệu callback không serialize vào Scene.

onEnable() {
  this.junction?.AddOnReachEvent(this.onReach, this);
  this.junction?.AddOnSwitchEvent(this.onSwitch, this);
}
onDisable() {
  this.junction?.RemoveOnReachEvent(this.onReach, this);
  this.junction?.RemoveOnSwitchEvent(this.onSwitch, this);
}
private onReach(e: JunctionEvent) {
  console.log(e.entryIndex, e.progress, e.direction);
}

EventHandler trong Inspector

Có thể dùng EventHandler kéo-thả hoặc callback TypeScript. Hai cơ chế hoạt động độc lập. onReach chỉ thông báo, onSwitch được gửi sau khi Animate thực sự chuyển spline.
