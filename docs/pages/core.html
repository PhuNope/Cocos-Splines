Spline Container & Knot

Quản lý knot, tangents, hệ 2D/3D và các API tính hình học.

1. Container

SplineContainer giữ danh sách các Knot, bộ cache độ dài và các phép tính Bezier. Container không tự tạo mesh vật lý.

Thuộc tínhÝ nghĩa
closedNối knot cuối về knot đầu
reversedĐảo hướng đọc spline
dimensionSpace3D, XY2D hoặc XZ2D
samplesPerCurveSố mẫu xây bảng độ dài Bezier
showGizmos / showTangentGizmosHiển thị đường và tangent trong Editor

2. Knot

Mỗi Knot là một node con có component SplineKnot. Có các Tangent Mode: AutoSmooth, Linear, Mirrored, Continuous, Broken. Có thể bật Edit Tangent Handles để kéo trực tiếp handle (khi có Node handles).

3. API

const length = spline.length;                   // local arc units
const point = spline.evaluateWorldPosition(.5); // normalized centerline distance
const t = spline.tAtProgress(.5);               // normalized arc -> Bezier t
const world = spline.evaluateWorldPositionAtT(t);
spline.refresh(); // invalidate internal spline arc cache
Đổi vị trí Knot bằng script: các phép evaluate sẽ cập nhật cache theo dữ liệu. refresh() hữu ích khi công cụ ngoài thay đổi cấu trúc hoặc tangent.
