Positioner / Projector

Đặt object theo vị trí t/distance và tìm điểm gần nhất trên spline trong world space.

SplinePositioner

Đặt object tĩnh tại progress hoặc Distance. Có Follow Target và Follow Distance, offset và align rotation; Editor preview opt-in.

positioner.positionMode = SplinePositionMode.Distance;
positioner.distance = 3;
positioner.applyPosition();

SplineProjector

Chiếu vị trí world-space của một Node lên điểm gần nhất thuộc spline. Hỗ trợ Snap To Spline và bán kính detect.

const hit = projector.projectNow();
if (hit) {
  console.log(hit.progress, hit.distance, hit.worldPosition);
}
projector.AddOnProjectEvent(this.onProject, this);
projector.AddOnEnterEvent(this.onEnter, this);
projector.AddOnExitEvent(this.onExit, this);

Query trực tiếp từ Spline

const hit = spline.projectWorld(worldPoint, 128);
// hit.t, hit.progress, hit.distance, hit.worldPosition, hit.squaredDistance
Projector thực hiện phép tính trong world space, phù hợp cả khi spline Node có non-uniform scale.
