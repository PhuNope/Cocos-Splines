Chẩn đoán offset

  1. Đặt Easing = Linear.
  2. Tắt Speed modifier keyframe để so sánh, hoặc đặt mọi key = 1.
  3. Đặt constantSpeedWithOffset = true.
  4. Kiểm tra có Knot bị gãy góc, spline bị scale động hoặc offset lớn hơn bán kính cong không.
  5. Với Speed mode, dùng cùng dt khi đo quãng đường object sau 1 giây.
Tham chiếu code dựa trên runtime v0.9.1; chưa thay thế kiểm thử trực tiếp trong Editor/Build thực.
