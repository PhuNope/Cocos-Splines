Spawn Prefab / Object Controller

Tạo bản sao prefab trực tiếp vào Scene Hierarchy hoặc tạo tự động khi Play mà không sinh trùng.

Quy trình trong Inspector

  1. Chọn Node chứa SplineInstantiate hoặc SplineObjectController; gán Spline và Prefab (hoặc danh sách Prefabs).
  2. Chọn phân phối Count hoặc Distance, chỉnh Count/Spacing, khoảng Start/End và Parent Node tùy chọn.
  3. Nhấn Spawn để tạo lần đầu vào Hierarchy; các node nằm trong nhóm Spline Instances (Generated) hoặc Spline Objects (Generated). Lưu Scene để lưu các bản sao.
  4. Nhấn Respawn khi đổi cấu hình và muốn thay toàn bộ bản sao. Clear Spawned xóa các bản sao do component sở hữu.
Không tạo trùng lúc Play: nếu nhóm spawned đã có con được lưu vào Scene thì spawnOnStart=true cũng không sinh thêm. Có thể đặt spawnOnStart=false để chỉ Spawn bằng tay.
Nút Respawn và Clear Spawned xóa các Node bên trong nhóm generated; không đặt object chỉnh tay vào nhóm này. Child riêng khác của Parent Node sẽ không bị đụng tới.

Khác nhau giữa hai component

SplineInstantiateSplineObjectController
PrefabMột prefabDanh sách prefabs, chọn có seed
RangeNormalized Distance, Distance hoặc Spline tNormalized progress 0–1

API chung

APIÝ nghĩa
spawnOnStart: booleanMặc định true. Tự Spawn khi Play chỉ nếu chưa có instances được lưu.
spawnedRoot: Node | nullReference được serialize tới nhóm instance; tự quản lý, không cần chỉnh.
spawn(): numberChỉ spawn khi root trống; trả số node vừa tạo, trả 0 khi đã có object.
respawn(): numberXóa các con của nhóm owned và tạo lại, trả về số node mới.
clear(): voidXóa các con owned trong nhóm spawned; không xóa sibling ngoài nhóm.
rebuild(): voidAlias cũ cho respawn(); vẫn giữ để script cũ tương thích.
rebuildOnChange: booleanChỉ tự cập nhật trên những object spawn động trong Play; không sửa các bản đã lưu bằng tay.

TypeScript ví dụ

import { SplineInstantiate } from 'db://cocos-splines/splines/Components/SplineInstantiate';
import { SplineObjectController } from 'db://cocos-splines/splines/Components/SplineObjectController';

// Gọi từ script gameplay hoặc Editor tooling:
instantiator.spawnOnStart = false;
instantiator.spawn();       // Chỉ tạo nếu chưa có object
instantiator.respawn();     // Luôn sinh lại
instantiator.clear();       // Dọn object do component sở hữu

controller.spawnOnStart = true;
controller.spawn();         // Không sinh trùng nếu Scene đã lưu clones

Vòng đời object

Object sinh qua nút Inspector được lưu vào Scene và giữ nguyên khi vào/thoát Play. Object sinh tự động trong gameplay được component dọn khi disable/destroy. Nút Respawn trong Editor có thể thay đổi hierarchy đã lưu nên cần lưu Scene sau thao tác.
