Example: Đoàn tàu nhiều toa

Đầu máy kéo nhiều toa theo arc distance; hướng dẫn một spline và tuyến nhiều spline qua ngã rẽ.

Mục tiêu: đầu máy đi trước, các toa giữ khoảng cách theo chiều dài đường ray, xoay theo tangent tại vị trí riêng. Các toa không cần tự chạy đồng hồ Animate.

Nguyên lý giống ví dụ tàu của Dreamteck

Không lấy vị trí world của đầu máy rồi trừ một vector cố định: ở khúc cua, toa sẽ lệch khỏi ray. Thay vào đó, tất cả đầu máy/toa lấy mẫu cùng một tọa độ quãng đường trên tuyến:

headDistance = 32 units
spacing = 5 units
Đầu máy:  distance = 32
Toa 1:    distance = 27
Toa 2:    distance = 22
Toa 3:    distance = 17

Khoảng cách ở đây là khoảng cách dọc ray (arc length), không phải khoảng cách Euclid giữa tâm toa. Đầu máy ở đoạn cong, mỗi toa dùng tangent tại vị trí của nó để quay theo đường.

Ví dụ không sử dụng ObjectBender để nối toa. ObjectBender dùng để uốn hình học từng model; đoàn tàu cần nhiều node độc lập bám ray. Đây là cách triển khai mẫu cho Cocos Splines, không phải bản sao trực tiếp của script Dreamteck.

Example A — Một spline: SplineAnimate + SplinePositioner

Hierarchy

Scene
├─ RailPath                 [SplineContainer] (+ các Knot)
├─ Locomotive              [SplineAnimate, Target = Locomotive]
├─ Wagon_01                [SplinePositioner]
├─ Wagon_02                [SplinePositioner]
├─ Wagon_03                [SplinePositioner]
└─ TrainManager            [TrainSingleSpline]

Thiết lập Inspector

Node / ComponentThiết lập
Locomotive / SplineAnimateSpline = RailPath; Method = Speed; Easing = Linear; LoopMode = Once (đường mở); JunctionMode = Off; Align To Spline = ON; Start Position Mode = Distance.
Wagon / SplinePositionerSpline = RailPath; Target để trống (di chuyển chính node); Position Mode = Distance; Align To Spline = ON; Follow On Update = OFF.
TrainManager / TrainSingleSplineLocomotive = SplineAnimate; Wagons = 3 Positioner theo đúng thứ tự từ đầu tới đuôi; Center Spacing = khoảng cách tâm toa.
Khoảng StartStart Distance của Animate phải >= số toa × Center Spacing nếu muốn toàn bộ đoàn tàu nằm sẵn trên ray.

Tạo file script TrainSingleSpline.ts trong assets/ của project, dán code dưới đây; hoặc xem bản TypeScript đầy đủ.

import { _decorator, Component } from 'cc';
import { SplineAnimate } from 'db://cocos-splines/splines/Components/SplineAnimate';
import { SplinePositioner } from 'db://cocos-splines/splines/Components/SplinePositioner';
import { SplinePositionMode } from 'db://cocos-splines/splines/Core/SplinePosition';

const { ccclass, property } = _decorator;

/** One spline only. The locomotive owns playback; wagons have Positioners. */
@ccclass('TrainSingleSpline')
export class TrainSingleSpline extends Component {
    @property({ type: SplineAnimate }) locomotive: SplineAnimate | null = null;
    @property({ type: [SplinePositioner] }) wagons: SplinePositioner[] = [];
    @property({ min: 0.01 }) centerSpacing = 3;
    @property() wrapClosed = false;

    start(): void {
        for (const wagon of this.wagons) {
            wagon.followOnUpdate = false; // This controller is the sole writer.
            wagon.followTarget = null;
            wagon.positionMode = SplinePositionMode.Distance;
        }
    }

    lateUpdate(): void {
        const engine = this.locomotive;
        const spline = engine?.currentSpline;
        if (!engine || !spline || spline.length <= 0) return;
        const headDistance = engine.currentDistance;
        this.wagons.forEach((wagon, index) => {
            if (!wagon) return;
            let d = headDistance - (index + 1) * this.centerSpacing;
            if (this.wrapClosed && spline.closed) {
                d = ((d % spline.length) + spline.length) % spline.length;
            } else if (d < 0) {
                return; // Engine must start far enough ahead to fit the train.
            } else {
                d = Math.min(spline.length, d);
            }
            wagon.spline = spline;
            wagon.distance = d;
            wagon.applyPosition();
        });
    }
}

Chạy thử

  1. Tạo ray dài tối thiểu 30 units; dùng ba toa spacing 5 units, đặt Engine Start Distance = 16.
  2. Trong Inspector gắn từng SplinePositioner vào mảng Wagons theo thứ tự đầu → cuối.
  3. Nhấn Play: đầu máy tiến, từng toa giữ quãng đường lệch 5/10/15 units dọc cùng spline.
  4. Với đường vòng kín, bật wrapClosed=true đồng thời bảo đảm SplineContainer.closed = ON; không bật trên đường hở.
Giới hạn của Example A: khi Animate tự đổi spline ở Junction, currentDistance tính trên spline đích; chỉ cập nhật wagon.spline sang spline mới sẽ khiến tất cả toa nhảy tuyến trước khi tới Junction. Vì vậy Example A chỉ dành cho một spline hoặc một loop kín, không dùng để đi qua Junction giữa nhiều spline.

Example B — Nhiều spline, đoàn tàu qua Junction không nhảy toa

Với nhiều spline, một đầu máy có thể đã sang Spline B trong khi toa cuối vẫn nằm trên Spline A. Để giữ tuyến tàu, cần dùng route có thứ tự và lấy mẫu theo quãng đường toàn tuyến thay vì dùng currentDistance riêng của từng spline.

Sơ đồ route

Spline A (0 → 1) ──Junction──> Spline B (0 → 1)
      [   Engine →      ]    [ Toa 2 ][ Toa 3 ]

Route legs = [A forward, B forward]
TrainRouteConsist.cars = [Locomotive, Wagon_01, Wagon_02, Wagon_03]

Đến ngã ba: chọn route [A, C] thay [A, B] trong Inspector.
Các toa vẫn vào đúng nhánh đã chọn khi đến lượt.

Cấu hình

Thuộc tínhVí dụ / Ý nghĩa
LegsDanh sách SplineContainer theo thứ tự đường đi; chọn Backwards cho đoạn chạy từ progress 1 về 0.
Cars[Engine, Wagon_01, Wagon_02, ...] đúng thứ tự. Không gắn thêm SplineAnimate hoặc Positioner đang auto update cho các Node này.
Center SpacingKhoảng cách tâm-to-tâm dọc tuyến, ví dụ 5 units.
Start DistanceÍt nhất (Cars.length - 1) × Center Spacing trên đường mở.
Speed / Loop RouteTốc độ theo route (units/giây); Loop Route chỉ bật nếu cuối leg cuối nối về đầu leg đầu.
ScaleĐặt spline Node scale = (1,1,1) để 1 local length = 1 world unit. Non-uniform scale cần LUT độ dài world riêng, sample này chưa xử lý.

Tạo file TrainRouteConsist.ts trong assets/ của project, gắn lên TrainManager, điền Legs/Cars trong Inspector. Xem file TypeScript đầy đủ.

import { _decorator, Component, Node, Quat } from 'cc';
import { SplineContainer } from 'db://cocos-splines/splines/Core/SplineContainer';

const { ccclass, property } = _decorator;

/** One leg of a preplanned, continuous train route. */
@ccclass('TrainRouteLeg')
export class TrainRouteLeg {
    @property({ type: SplineContainer }) spline: SplineContainer | null = null;
    @property() backwards = false;
}

/** Route spans several splines: every wagon samples the same route history. */
@ccclass('TrainRouteConsist')
export class TrainRouteConsist extends Component {
    @property({ type: [TrainRouteLeg] }) legs: TrainRouteLeg[] = [];
    @property({ type: [Node] }) cars: Node[] = []; // [locomotive, wagon 1, ...]
    @property({ min: 0.01 }) centerSpacing = 3;
    @property({ min: 0 }) speed = 4;
    @property({ min: 0 }) startDistance = 12;
    @property() loopRoute = false;
    @property() playOnStart = true;

    private headDistance = 0;
    private playing = false;
    private readonly turnAround = Quat.fromEuler(new Quat(), 0, 180, 0);

    start(): void {
        this.headDistance = this.startDistance;
        this.playing = this.playOnStart;
        this.placeCars();
    }

    update(dt: number): void {
        if (this.playing && Number.isFinite(dt) && dt > 0) {
            this.headDistance += this.speed * dt;
        }
        this.placeCars();
    }

    public play(): void { this.playing = true; }
    public pause(): void { this.playing = false; }
    public seekRouteDistance(distance: number): void {
        this.headDistance = Math.max(0, distance);
        this.placeCars();
    }

    private placeCars(): void {
        const usable = this.legs.filter(
            (leg) => !!leg && !!leg.spline && leg.spline.count >= 2 && leg.spline.length > 0,
        );
        const total = usable.reduce((sum, leg) => sum + leg.spline!.length, 0);
        if (total <= 0) return;

        this.cars.forEach((car, index) => {
            if (!car || !car.isValid) return;
            let routeDistance = this.headDistance - index * this.centerSpacing;
            if (this.loopRoute) {
                routeDistance = ((routeDistance % total) + total) % total;
            } else {
                // Avoid stacking wagons at route start: choose startDistance
                // >= (cars.length - 1) * centerSpacing in the Inspector.
                if (routeDistance < 0) return;
                routeDistance = Math.min(routeDistance, total);
            }

            for (let i = 0; i < usable.length; i++) {
                const leg = usable[i];
                const spline = leg.spline!;
                const length = spline.length;
                const last = i === usable.length - 1;
                if (routeDistance > length && !last) {
                    routeDistance -= length;
                    continue;
                }
                const localDistance = Math.max(0, Math.min(length, routeDistance));
                const splineDistance = leg.backwards ? length - localDistance : localDistance;
                const progress = splineDistance / length;
                car.setWorldPosition(spline.evaluateWorldPositionAtDistance(splineDistance));
                const rot = Quat.multiply(
                    new Quat(), spline.node.worldRotation, spline.evaluateRotation(progress),
                );
                if (leg.backwards) Quat.multiply(rot, rot, this.turnAround);
                car.setWorldRotation(rot);
                break;
            }
        });
    }
}

Lưu ý khi các toa qua Junction

  • Các endpoint của hai leg phải trùng nhau trong world space, và tangent/up nối hợp lý; nếu khác nhau, tại đúng biên leg toa có thể đổi hướng đột ngột.
  • Hướng backwards nằm trong mỗi leg; nó không phải là JunctionExitDirection của SplineAnimate. Script này tự chạy theo route, không gọi JunctionMode.
  • Chuyển nhánh động theo sự kiện On Reach của đầu máy sẽ cần ghi lại lịch sử các leg thực sự đi qua rồi cho từng toa đọc lịch sử đó. Example B mới là route cố định, không tự ghi lịch sử rẽ nhánh runtime.
  • Khoảng cách theo ray không bảo đảm coupling cơ khí khi cua gắt: cần điều chỉnh spacing, pivot và bogie (bánh trước/sau) tùy độ dài model.

API tham khảo

  • SplineAnimate.currentDistance, currentSpline — dùng cho đầu máy trên một spline.
  • SplinePositioner.distance, applyPosition() — đặt các toa không dùng clock.
  • SplineContainer.evaluateWorldPositionAtDistance(), evaluateRotation(), length — lấy mẫu toàn tuyến.
  • Junction / Routing — so sánh giới hạn route cố định và rẽ nhánh runtime.
  • Object Bender — uốn mesh nhiều phần; không phải cơ chế giữ khoảng cách toa.
