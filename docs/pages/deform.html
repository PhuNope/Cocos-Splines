Mesh Deform

Hướng dẫn Capsule/Tube, Axis X/Y/Z, Stretch/Repeat, UV và xử lý normals/tangents.

MeshDeform

Uốn mesh import theo spline. Source mesh cần CPU-readable, có đủ phân đoạn dọc trục uốn, giới hạn một submesh non-skinned.

Thuộc tínhÝ nghĩa
Axis X/Y/ZChiều dài ban đầu của mesh nguồn
StretchKéo mesh ra theo chiều dài range
RepeatLặp mesh nhiều lần theo spline
Flip FacesĐảo triangle winding và normals; với Axis Y mặc định để OFF
UV KeepOriginalGiữ UV mesh nguồn
UV ContinuousRepeatNối UV giữa các bản repeat
UV DistanceV = distance * UV Tiles Per Unit
UV Tiles Per Unit = 1Lặp một lần mỗi world/local unit tùy phép tạo UV

Material / shading

Sử dụng setSharedMaterial để gán asset. Deform có sinh normals và tangents cho builtin-standard; riêng effect rope-uv-repeat minh họa thuộc loại unlit. Khi texture không lặp, kiểm tra Texture Wrap Mode = Repeat.

Nếu nhìn chỉ mặt sau, thử Flip Faces và kiểm tra Cull Mode. Nếu bị đen với PBR, thử vô hiệu hóa Normal Map hoặc dùng Unlit để khoanh vùng.

Khung lưới Gizmos

Chọn Node chứa MeshDeform để xem wireframe của mesh đã tạo trong Scene Editor (cần Cocos-Gizmos). Bật Show Mesh Gizmos và tùy chỉnh Gizmo Edge Limit trong Inspector. Hình gizmos chỉ là trợ giúp biên tập; không sinh thêm MeshRenderer hay Material.
