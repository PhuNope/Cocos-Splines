Cài đặt & cấu trúc

Hướng dẫn cài extension và import TypeScript API của Cocos Splines.

Cài extension vào project

  1. Đóng Cocos Creator và sao lưu project.
  2. Giải nén plugin, đặt thư mục cocos-splines bên trong extensions/ của project.
  3. Mở Cocos Creator từ phiên bản 3.8.2 trở lên, bật extension trong Extension Manager (nếu chưa bật).
  4. Vào menu Extensions → Cocos Splines → Create Spline để tạo spline thử nghiệm.
MyCocosProject/
├─ assets/
├─ extensions/
│  └─ cocos-splines/
│     ├─ assets/splines/
│     ├─ dist/
│     ├─ docs/
│     └─ package.json
└─ settings/

Import TypeScript

import { SplineContainer } from 'db://cocos-splines/splines/Core/SplineContainer';
import { SplineAnimate } from 'db://cocos-splines/splines/Components/SplineAnimate';
import { SplineObjectBender } from 'db://cocos-splines/splines/Components/SplineObjectBender';

Hãy gán SplineContainer ở Node nguồn; SplineAnimate có thể đặt ở node cần di chuyển hoặc node điều khiển. Để dùng source mesh đã import với MeshDeform/ObjectBender, bật Allow Data Access trên asset mesh.
