Cài đặt & cấu trúc

Cấu trúc dự án, cách cài đặt extension và đường dẫn import API trong Cocos.

1. Cài extension

  1. Giải nén bản plugin, bảo đảm thư mục có package.json.
  2. Đặt trong <project>/extensions/cocos-splines/.
  3. Mở Cocos Creator 3.8.8, bật extension, chờ asset DB import script.
  4. Trong Hierarchy: chọn node rồi dùng menu Extensions → Cocos Splines hoặc thêm component bằng Inspector.
my-project/
  assets/
  extensions/
    cocos-splines/
      package.json
      assets/splines/Core/
      assets/splines/Components/
      docs/index.html
      dist/

2. Import TypeScript

import { SplineContainer } from 'db://cocos-splines/splines/Core/SplineContainer';
import { SplineAnimate } from 'db://cocos-splines/splines/Components/SplineAnimate';
Mở tài liệu trực tiếp bằng file:// được. Không cần chạy Vite, webpack hay HTTP server.

3. Khi nâng cấp

Sao lưu scene/prefab; tắt Editor trước khi thay extension. UUID của các runtime script cũ được giữ nguyên; bật lại extension rồi kiểm tra Console. Nếu Inspector hiển thị dữ liệu cũ, reload Editor.
