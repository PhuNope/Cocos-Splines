Animate Up Mode và Junction Exit Direction

import { SplineUpMode } from 'db://cocos-splines/splines/Components/SplineAnimate';
import { JunctionExitDirection } from 'db://cocos-splines/splines/Components/SplineJunction';
animate.upMode = SplineUpMode.TargetLocal;
animate.upReference = upGuideNode;
animate.junctionOffsetBlendDistance = 2;
link.exitDirection = JunctionExitDirection.Forward; // tăng Progress
link.exitDirection = JunctionExitDirection.Backward; // giảm Progress
link.exitDirection = JunctionExitDirection.Preserve; // giữ chiều trước Junction
Tham chiếu phương thức TypeScript thật trong assets/splines/Components và assets/splines/Core; tài liệu ưu tiên mô tả API public, không dùng private method.
