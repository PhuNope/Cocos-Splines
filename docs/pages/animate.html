Spline Animate

Điều khiển follower theo spline: tốc độ, Easing, Offset và chuyển nhánh qua Junction.

Up Mode theo local object

Bật Align To Spline, chọn Up Mode = Target Local. Plugin lấy local +Y ban đầu của Target chuyển sang world làm hướng tham chiếu cố định. Nếu cần cập nhật động, gán một Up Reference Node riêng, plugin dùng local +Y của Node đó theo world rotation tại mỗi frame.

Không gán chính animated Target làm Up Reference để tránh feedback. Up Mode chỉ điều khiển rotation; Spline Offset vẫn dùng frame của spline.

animate.alignToSpline = true;
animate.upMode = SplineUpMode.TargetLocal;
animate.upReference = guideNode; // optional

Tại sao Offset làm nhanh/chậm dù Easing Linear?

Ở đoạn cong, quỹ đạo lệch khỏi tâm có độ dài khác đường spline gốc. Khi bật Constant Speed With Offset, follower dùng bảng độ dài quỹ đạo trong world space để giữ vận tốc đều, kể cả khi Easing = Linear.

const animate = this.node.getComponent(SplineAnimate)!;
animate.method = AnimateMethod.Speed;
animate.speed = 4;
animate.easing = Easing.Linear;
animate.splineOffset.set(2, 0, 0);
animate.constantSpeedWithOffset = true;
animate.restart();
console.log(animate.currentProgress, animate.currentDistance, animate.currentT);

Spline Offset khi đi qua Junction

Offset X/Y/Z được áp dụng trong hệ trục của từng spline. Khi hai spline có hướng khác nhau, cùng một giá trị offset có thể trỏ đến hai vị trí world khác nhau. Để tránh follower nhảy tức thời, Junction Offset Blend Distance giữ đúng vị trí tại điểm nối rồi chuyển tiếp sang offset của spline mới theo độ dài quãng đường.

Giữ Junction Offset Blend Distance > 0 để chuyển mượt. Đặt bằng 0 nếu muốn dịch chuyển offset ngay khi rẽ nhánh. Các connection nên có cùng vị trí world để tránh đoạn chuyển quá dài. Tùy chọn này chỉ làm mượt vị trí; hướng quay vẫn phụ thuộc tangent/Up của spline đích.

animate.splineOffset.set(1, 0, 0);
animate.junctionOffsetBlendDistance = 2; // units trên nhánh mới
animate.constantSpeedWithOffset = true;

API điều khiển

animate.play();
animate.pause();
animate.restart();
animate.reverseTravel();
animate.seekDistance(5, false);
animate.seekAtT(0.5);
animate.setCurrentSpline(nextSpline, 0, 1);
animate.setCurrentSplineAtDistance(nextSpline, 3, -1);
LUT chỉ được tạo khi có Spline Offset / Modifiers Offset thực sự khác 0 và compensation bật. Đường cong có cusp, góc gãy hoặc offset quá lớn so với bán kính cong vẫn có thể có biến động nhỏ do hình học không trơn.
