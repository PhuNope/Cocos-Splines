t, Distance, Progress

Phân biệt tiến độ hình học, khoảng cách dọc spline và khoảng cách thực của follower offset.

Phân biệt ba hệ tọa độ

HệMiền giá trịCách hiểu
Normalized Distance0 → 1Tỉ lệ độ dài cung của spline gốc, thường cho tốc độ đều trên tâm đường
Distance0 → spline.lengthKhoảng cách thực trên tâm spline (local units)
Spline t0 → 1Tham số Bezier phân bổ đều theo từng segment, không đều theo độ dài
const p = spline.progressAtT(0.5);           // Bezier t -> normalized distance
const t = spline.tAtProgress(0.5);            // normalized distance -> Bezier t
const t2 = spline.tAtDistance(3.5);           // local distance -> Bezier t
const d = spline.distanceAtT(t2);
const result = spline.projectWorld(worldPoint); // nearest world position, t, progress, distance

Đối với Animate có Offset

currentProgress vẫn là tiến độ tâm đường để các Trigger/Junction giữ nguyên tọa độ; riêng phép tăng thời gian sẽ tính theo quỹ đạo offset thực khi bật Constant Speed With Offset.

Trong Method Speed, đơn vị của speed khi có offset compensation là world units/second. Khi tắt compensation, behavior cũ dựa trên spline.length theo local units.
